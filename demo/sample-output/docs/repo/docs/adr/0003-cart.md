# 0003. 购物车（Cart） 的实现约定

**Status**: Proposed
**Date**: 2026-10-21
**Related Spec**: `specs/001-cart/spec.md`

## Context

规格 `specs/001-cart/spec.md`（**Status**: Implemented）中的 2 条需求已由代码核对通过。

## Decision

- Checkout MUST call `POST /api/orders` with the cart items.
- The cart screen MUST expose the testID `cart_checkout`.

## Consequences

改动这些行为时需要同步更新规格与本 ADR；`kb docs stale-specs` 会报告规格与代码的偏离。
