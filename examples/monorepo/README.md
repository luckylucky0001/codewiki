# MonoShop (codewiki docs-ownership example)

Two app projects (`apps/shop-android`, `apps/shop-ios`) built from the minishop sources, shared
specs under `specs/` (spec-kit) and `.kiro/specs/` (Kiro), human-written root docs under `docs/`
and per-project docs/specs. Used by `demo/docs-demo.sh` to show `kb docs …` (SFK ownership):
adopted / skeleton / new files, the human-content guard, routing by evidence and spec trust.
